# Security Policy — JTBS Classic

---

## 🛡️ Supported Versions

Only the latest official release of the **JTBS Classic** application and broadcast services are actively maintained for security and stability updates.

| Version | Supported |
| ------- | --------- |
| **v9.0.x** | ✅ Yes (Current Active Release) |
| **v8.0.x** | ⚠️ Deprecated (Please upgrade to v9.0.2+) |
| **< v8.0.0** | ❌ No |

## 🔒 Reporting a Vulnerability or Security Concern

We take the security, data privacy, and integrity of our broadcast platform seriously.

If you discover a security vulnerability, authentication issue, or unauthorized stream piracy concerning **JTBS Classic**, please report it directly to us via email rather than filing a public issue.

## ⚖️ Anti-Piracy & Content Protection

- **Stream Integrity**: Unauthorized scraping, hijacking, or re-streaming of our direct live broadcast links without prior authorization is strictly prohibited.
- **Application Security**: Reverse engineering, decompiling, modifying, or re-distributing modified APK binaries of the official **JTBS Classic** mobile app is prohibited.
- **Authentic Downloads**: Only download official APK binaries directly from our [Official GitHub Releases Page](https://github.com/joelgomes001/jtbs-classic/releases).
